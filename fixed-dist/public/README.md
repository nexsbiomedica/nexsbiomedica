# NEXS BioMedica Website

This package contains a complete static website for NEXS BioMedica.

## Deployment Instructions

### Option 1: Deploy to a static web server

Simply upload all contents of this directory to the root of your web server.

### Option 2: Deploy to a cloud storage provider

This site can be hosted on services like:
- Amazon S3
- Azure Blob Storage (with Static Website hosting enabled)
- Google Cloud Storage
- Netlify
- Vercel

### Option 3: Local testing

If you want to test the site locally before deployment, you can use any simple HTTP server:

Using Python:
```
python -m http.server
```

Using Node.js:
```
npx serve
```

## Directory Structure

- `/` - Root directory with main HTML files
- `/images/` - All image assets
- `/videos/` - Video files
- `/pdfs/` - PDF documents (if any)
- `/investors/` - Investors page (for deep linking)
